# Arctg через ряд (лабораторная работа 1)

Программа вычисляет arctg(x) при x ≥ 1 с заданной точностью, используя разложение в знакочередующийся ряд:

```
arctg(x) = π/2 − 1/x + 1/(3x³) − 1/(5x⁵) + …
```

Точность задаётся параметром `k`: суммирование продолжается, пока очередной член ряда больше 10^(−k). Для проверки рядом выводится значение стандартной функции `atan(x)`.

## Формат ввода

- `x` и `k` — натуральные числа, вводятся через пробел (x ≥ 1, k ≥ 1).
- При некорректном вводе выводится `Error`.

## Пример

```
Enter x > 0 and k > 0 : 2 5
1.10715 1.10715
```

## Сборка и запуск

```
g++ arctg.cpp -o arctg
./arctg
```
