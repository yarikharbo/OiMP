# Квадратная матрица: максимум и перестановка (лабораторная работа 4)

Программа работает с квадратной матрицей целых чисел (память выделяется динамически через `new`):

1. Вводит размер матрицы (от 1 до 100).
2. Заполняет матрицу одним из способов: вручную, случайно через `rand()` или случайно через генератор Мерсенна (`std::mt19937`) с заданными границами.
3. Находит **максимальный элемент в нижнем правом треугольнике** — строго ниже побочной диагонали.
4. Находит максимальный элемент всей матрицы и **переставляет строки и столбцы** так, чтобы он оказался в левом верхнем углу (меняются местами строка 0 и строка с максимумом, столбец 0 и столбец с максимумом).

## Сборка и запуск

```
g++ 3.cpp -o lab4
./lab4
```

## Состав

- `3.cpp` — исходный код (3 — номер варианта задания)
- `3.exe`, `3.o` — скомпилированные файлы (Windows)
