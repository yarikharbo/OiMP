# Простые числа в строке (лабораторная работа 8)

Программа на основе `std::string` и решета Эратосфена:

1. Запрашивает символ-разделитель (знак препинания или спецсимвол).
2. Запрашивает строку.
3. Извлекает из строки все целые числа (фрагменты, разделённые указанным символом).
4. С помощью **решета Эратосфена** (числа до 10 000) находит и выводит все **простые числа** среди извлечённых.

## Сборка и запуск

```
g++ 3.cpp -o lab8
./lab8
```

## Состав

- `3.cpp` — исходный код (3 — номер варианта задания)
- `3.exe`, `3.o` — скомпилированные файлы (Windows)
