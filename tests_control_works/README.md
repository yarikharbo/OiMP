# Контрольные работы и зачёт

Самостоятельные и контрольные работы по курсу:

| Файл | Что делает |
|------|------------|
| `control_1.cpp` | Записывает строку в квадратную матрицу по строкам (пустые ячейки заполняются `*`) и читает её по столбцам — перестановочная «шифровка» строки |
| `Горбатовский_вариант2.cpp` | Читает `input.txt` (первая строка — набор символов-разделителей, далее два целых числа a и b, далее текст); удаляет из каждой строки все целые числа из диапазона [a, b]; удалённые числа и изменённые строки пишет в `output.txt` |
| `control_3.cpp` | Черновик контрольной: чтение чисел из файлов с разделителем (в текущем виде не завершён и не компилируется) |
| `Zachet/` | Зачётная работа |

## Папка Zachet

`zachet_char.cpp` — читает файлы `integers.txt` и `double.txt` (первый символ каждого файла — разделитель чисел) и выводит элементы, которые **«меньше» обоих своих соседей**:

- для целых чисел сравнение идёт по сумме цифр;
- для вещественных — по дробной части.

## Сборка и запуск

Каждая программа компилируется отдельно, например:

```
g++ control_1.cpp -o control_1
./control_1
```
