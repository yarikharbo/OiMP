# Подсчёт слова в текстовом файле (лабораторная работа 9)

Программа читает текстовый файл `input.txt`:

- первое слово файла считается искомым;
- программа подсчитывает, **сколько раз это слово встречается в остальном тексте**, и выводит результат в консоль.

Если файл не существует или пуст, выводится сообщение об ошибке.

## Формат `input.txt`

Первое слово — искомое, далее — произвольный текст. Пример:

```
fo
fo fo цфывафавф abvgd of . 5 /' '
```

Результат: `2`.

## Сборка и запуск

```
g++ 3.cpp -o lab9
./lab9
```

## Состав

- `3.cpp` — исходный код (3 — номер варианта задания)
- `input.txt` — пример входных данных
- `3.exe`, `3.o` — скомпилированные файлы (Windows)
