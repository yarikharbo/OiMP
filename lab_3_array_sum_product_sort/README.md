# Одномерный массив: сумма, произведение, сортировка (лабораторная работа 3)

Программа работает с одномерным массивом вещественных чисел:

1. Вводит размер массива (от 1 до 100).
2. Заполняет массив случайно (с заданными границами значений) или числами, введёнными вручную (|элемент| ≤ 100).
3. Вычисляет **сумму положительных элементов**.
4. Вычисляет **произведение элементов**, расположенных между минимальным и максимальным по модулю элементами (при больших значениях выводится в виде «целая часть · 10⁶ + остаток»).
5. Сортирует **элементы с чётными индексами по убыванию** и выводит отсортированный массив.

## Сборка и запуск

```
g++ 8.cpp -o lab3
./lab3
```

## Состав

- `8.cpp` — исходный код (8 — номер варианта задания)
- `8.exe`, `8.o` — скомпилированные файлы (Windows)
