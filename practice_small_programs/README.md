# Практические задачи

Небольшие самостоятельные программы:

| Файл | Что делает |
|------|------------|
| `concat.cpp` | Заполняет два массива случайными числами, сортирует их и сливает в один отсортированный массив (алгоритм merge) |
| `NumberOfDigits.cpp` | Подсчитывает, сколько раз каждая цифра встречается во введённом числе |
| `file.cpp` | Построчно копирует `input.txt` в `output.txt` с проверкой того, что файлы открылись и входной файл не пуст |

## Сборка и запуск

Каждая программа компилируется отдельно, например:

```
g++ concat.cpp -o concat
./concat
```
