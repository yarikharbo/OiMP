# Задачи на цифры числа (лабораторная работа 2)

Шесть небольших программ, работающих с цифрами натурального числа. Каждая решает свой вариант задания, данные читаются из консоли, результат выводится в консоль.

| Файл | Задача |
|------|--------|
| `001.cpp` | Проверить, есть ли в числе повторяющиеся цифры |
| `002.cpp` | Удалить из числа все цифры, кратные его минимальной цифре (если минимальная цифра — 0, число не меняется) |
| `006.cpp` | Разложить число на простые множители |
| `010.cpp` | Вывести все числа Армстронга, не превышающие N |
| `016.cpp` | Проверить, можно ли получить число A, удалив несколько цифр из числа B |
| `019.cpp` | Вывести все пифагоровы тройки (a² + b² = c²) с числами, не превышающими N |

## Формат ввода

Одно или два натуральных числа с консоли. При некорректном вводе выводится `Error`.

## Сборка и запуск

Каждая программа компилируется отдельно, например:

```
g++ 006.cpp -o 006
./006
```
