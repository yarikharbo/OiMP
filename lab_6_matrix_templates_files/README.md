# Матрицы: шаблоны функций и файловый ввод/вывод (лабораторная работа 6)

Программа сортирует строки матрицы по возрастанию или убыванию. Сортировка реализована через **шаблоны функций**, поэтому матрица может состоять из элементов типов `int`, `double` или `std::string`.

Три режима работы:

1. **Ввод из файла** — данные читаются из `input.txt`, результат пишется в `output.txt`.
2. **Случайная генерация** — матрица создаётся случайно (int/double — с границами от −100 до 100, string — случайные строки заданной длины от 1 до 10) и выводится в консоль.
3. **Чтение из файла с выводом в консоль**.

## Формат `input.txt`

```
<число строк> <число столбцов>
<тип элементов: 1 - int, 2 - double, 3 - string>
<элементы матрицы>
<тип сортировки: 1 - по возрастанию, 2 - по убыванию>
```

## Сборка и запуск

```
g++ 3.cpp -o lab6
./lab6
```

## Состав

- `3.cpp` — исходный код (3 — номер варианта задания)
- `input.txt` — пример входных данных
- `output.txt` — результат работы программы
- `3.exe`, `3.o` — скомпилированные файлы (Windows)
