# Слова-палиндромы в C-строках (лабораторная работа 7)

Программа работает со строками в стиле C (`char*`, память выделяется вручную через `new` и освобождается `delete[]`):

1. Запрашивает символ-разделитель (знак препинания или спецсимвол).
2. Запрашивает строку (до 300 символов).
3. Разбивает строку на слова по разделителю и находит среди них **палиндромы**.
4. **Сортирует найденные палиндромы по длине** (по возрастанию) и выводит их через пробел.

## Сборка и запуск

```
g++ 3.cpp -o lab7
./lab7
```

## Состав

- `3.cpp` — исходный код (3 — номер варианта задания)
