# Класс Fraction: рациональные дроби (лабораторная работа 10)

Учебный класс `Fraction` — рациональная дробь с числителем и знаменателем — с полным набором **перегруженных операторов**:

- арифметика: `+`, `-`, `*`, `/` и составные `+=`, `-=`, `*=`, `/=`;
- сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`;
- унарные операции: `-` (смена знака), `!` (обращение дроби — переворот числителя и знаменателя);
- инкремент и декремент: префиксные и постфиксные `++` и `--`;
- ввод/вывод в поток в виде `числитель/знаменатель`.

Дробь автоматически **сокращается на НОД**, знаменатель всегда хранится положительным. Нулевой знаменатель и деление на ноль вызывают исключение.

## Сборка и запуск

```
g++ main.cpp fraction.cpp -o fraction
./fraction
```

## Состав

- `fraction.h` — объявление класса
- `fraction.cpp` — реализация
- `main.cpp` — демонстрация возможностей класса (в текущем виде файл содержит незавершённые фрагменты и не компилируется)
